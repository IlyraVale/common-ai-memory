# Privacy

The extraction contains no real memory, Lounge message, game state, attachment, screenshot, log, profile, browser state, deployment backup, process state, environment file, private address, account identifier, or credential. Runtime paths are ignored.

GPT, Claude, and Alice are synthetic defaults. Lounge identities are configurable. The production category catalog was replaced with a generic catalog. Optional third-party and private systems are mentioned only to document exclusion; their source, assets, databases, endpoints, patches, deployment copies, and credentials are absent.

Run scripts/audit.py, inspect every lexical finding, run an independent secret scanner, and review the exact staged files before publication.
