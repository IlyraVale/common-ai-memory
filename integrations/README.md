# Optional external integrations

Adapters implement Common AI Memory protocols while the external project remains separately installed and separately licensed. No external project source, assets, database, runtime files, private service URL, or deployment copy is included here.

The executable adapter contract is `external_games.ExternalGameAdapter`. Garden, Tide Island, Hani Mail, Nowhere, and private MCP services require an operator-created adapter and their own official installation instructions. Public links are intentionally omitted until ownership and licensing can be verified.
